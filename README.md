# Neyora

Neyora est une expérience web de démonstration pour une startup algérienne qui met en relation entrepreneurs, producteurs et talents du digital.

## Le problème

De nombreux projets algériens ont de bons produits mais peinent à construire leur visibilité, leur identité de marque et une présence digitale efficace. Trouver les bons spécialistes reste également difficile.

## La solution

Neyora recueille le contexte d'un projet, aide à identifier ses besoins, puis l'oriente vers les compétences digitales pertinentes : community management, développement web, design, contenu, marketing et copywriting.

Ce projet n'est **pas une marketplace** : il ne comporte ni catalogue, ni panier, ni système de vente de produits.

## Fonctionnalités

- Navigation fluide et menu mobile accessible
- Animations d'apparition et interactions au survol
- Présentation visuelle du parcours de matching
- Sections spécialistes, accompagnements et étapes
- Formulaire de projet avec validation côté navigateur et confirmation simulée
- Bouton de retour en haut et interface entièrement responsive

## Technologies

- HTML5
- CSS3
- JavaScript vanilla

Aucune dépendance, installation, compilation ou connexion backend n'est requise.

## Structure

```text
.
├── index.html
├── style.css
├── script.js
└── README.md
```

## Lancer le projet

Ouvrez simplement `index.html` dans un navigateur. Le formulaire est une démonstration frontend : il valide les informations localement et n'envoie aucune donnée à un serveur.

Pour un usage réel, la logique de soumission dans `script.js` peut être remplacée par Formspree, EmailJS ou une API backend.

## GitHub Pages

Le projet est statique et compatible avec GitHub Pages : placez les fichiers à la racine de votre dépôt puis activez GitHub Pages depuis les paramètres du dépôt.
